1. Linear Mixed Models

Mixed Models VS Traditional ANOVA:

\(y_{ijk} = \mu + L_i + B(L)_{ij} + G_k + GL_{ik} + \epsilon_{ijk}\)

where: - \(y_{ijk}\) = observed value of the trait for the \(k^{th}\) genotype in the \(j^{th}\) block of the \(i^{th}\) location - \(\mu\) = overall mean - \(L_i\) = effect of the \(i^{th}\) location (fixed effect) - \(B(L)_{ij}\) = effect of the \(j^{th}\) block within the \(i^{th}\) location (random effect) - \(G_k\) = effect of the \(k^{th}\) genotype (fixed effect) - \(GL_{ik}\) = interaction effect between the \(i^{th}\) location and the \(k^{th}\) genotype (random effect) - \(\epsilon_{ijk}\) = random error term associated with the \(ijk^{th}\) observation, assumed to be normally distributed with mean 0 and variance \(\sigma^2\).
